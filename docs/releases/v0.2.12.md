# AI Team Skill v0.2.12

本次新增成果产出后的修改接续：补一句明确意见，交回原作者修改，再由原审阅者检查新版；不重新分工或生成未受影响的成果。

## 改了什么

- 原任务逐字保留，补充意见单独记录。主助手准备影响范围、当前版本和必要检查，不让用户填写内部参数。
- 继续原作者和原审阅者，保留旧成果、原始 Review Memo 和检查记录。已变化的内容不能直接沿用旧检查或旧第三方结论。
- 只修改明确范围，相关计算与依赖仍需重查；未受影响成果保持不变。范围越界、错版本、缺依据或未解决分歧时停止合并。
- 同一实例内重复送达的意见返回原回执，不再次执行；失败和中断也不自动重试。
- 新增 `feedback_demo.py` 和修改接续说明，复用原有 CCRL、交付检查、分歧处理及合并，没有新增默认角色、讨论轮数或真实模型连接。

例如：“把活动开场从20分钟改成10分钟，人员不变。”本地固定样例会修改开场并把合计从120分钟改为110分钟，保留人员和物品安排。

## 使用和限制

- 完整 Skill 流程仍需至少一个可用模型、三个可创建、保留并继续的独立子 Agent 会话；第三方仅在有剩余分歧时参与。
- 自然语言理解、影响范围和真实会话身份由主助手及宿主工具核实。会话不能继续时如实停止，不创建替代会话冒充原作者或审阅者。
- Python 接入仅限同一 `AITeam` 实例的当前成果；不提供重启恢复、跨进程去重、实时打断、多人权限或外部副作用撤销。
- 字符差异检查不证明语义正确、依赖完整、资料真实，也不是严格沙箱或身份认证。
- 原必要条件保留并可追加；新旧条件冲突时不静默删除旧条件，也不自动批准改变目标或扩大资料范围。
- 继续修改仍须处于本次有效授权和调用次数内；超范围真实调用、发布或其他外部写入仍需单独确认。

详见安装包中的 `references/feedback-continuation.md`。只阅读 Skill 不需要Python，附带脚本需要Python 3.11或以上。
